# RFC-0008 — Voz y TTS

## Componentes
Genesis TTS MX-Prime, IVCC (Cognitive Voice OS), consentimiento verificado antes de planear y antes de entregar audio.

## Requisitos
- `GROQ_API_KEY` para TTS por clave.
- Servicio neuronal del operador opcional (`ISABELLA_NATIVE_VOICE_ID`).
- Fallback navegador siempre disponible.
- Watermark firmado y auditoría encadenada.
- Hablar no autoriza ni ejecuta acciones.
- Consentimiento durable para IVCC (`IVCC_DATA_DIR`).
