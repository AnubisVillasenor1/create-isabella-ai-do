# Agent SDK Verifier

**Contexto:** subagente para verificar aplicaciones Python basadas en Agent SDK.

**Estado:** alpha.

**Dependencias:** Python, Agent SDK, documentación oficial, CI, ARGUS.

## Alcance

SDK/versiones, Python, dependencias, imports, prompts, modelos, permisos, MCP, subagentes, `.env.example`, `.gitignore`, secretos, errores, sintaxis y documentación.

## Estados

`PASS`, `PASS_WITH_WARNINGS`, `FAIL`, `INCONCLUSIVE`, `NOT_APPLICABLE`.

El resultado es evidencia de una revisión concreta; no es certificación universal de producción.
