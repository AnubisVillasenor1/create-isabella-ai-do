# TAMV Integration Map

**Contexto:** mapa de integración conceptual para TAMV MD-X5 y las bibliotecas de Isabella.

**Estado:** draft.

**Dependencias:** IKES, fuentes históricas TAMV, MSR, MDD, DreamSpaces, blindajes.

## Regla de honestidad

La documentación TAMV debe separar capacidad implementada, probada, verificada, experimental, simulada y planificada.

## Módulos

- MSR: registro y provenance.
- MDD: modelo económico sujeto a requisitos legales y operativos.
- DreamSpaces: experiencia web/XR por fases.
- Blindajes: controles de seguridad, no garantía de invulnerabilidad.
- Arquitectura territorial: contexto e identidad, no restricción técnica.

Los documentos fuente permanecen históricos hasta que claims, dependencias y evidencia sean migrados.
